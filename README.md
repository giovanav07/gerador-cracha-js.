# gerador-cracha-js.

## Objeto 
Página HTML com Javascript realiza as perguntas e coleta o nome,sobrenome e data de nascimento do usuário.Isso tem objetivo de coletar e processar esses dados para realizar uma organização das informações e exibir os resultados como um crachá virtual do usuário.

## Integrantes
-Dupla A: Giovana e Kauã
-Dupla B: Arthur e João

## Como funciona o trabalho em equipe
-cracha-1:Coleta feita pela Dupla A, geração feita pela Dupla B
-cracha-2:Coleta feita pela Dupla B, geração feita pela Dupla A

## Como executar
Baixe cracha-1/Index.html ou cracha-2/Index.html, abra no navegador, responda às perguntas e pressione F12 para ver a console.
